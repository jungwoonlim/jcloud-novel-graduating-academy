# 정합성 검수

`continuity-auditor` 에이전트가 사용한다. 이벤트 완성 **직후 점진 검수**한다 — 모순이 누적된 뒤에는 되돌릴 비용이 감당 불가능해진다.

> **2026-09-02 매체 전환.** 검수 대상이 `episodes/` 본문 → `design/events/` 명세 + `text/` 텍스트로 바뀌었다.
> 회귀 폐기로 "조연 기억 위반"·"회귀 카운트 정합" 검사는 소멸하고, "게임 어휘"·"도달 가능성"·"밸런스" 검사가 신설되었다.

---

## 검사 항목

### 1. 플래그 집합 대조 (CRITICAL)

텍스트 하단 `knowledge-used`의 ID 집합이 이벤트 명세의 **진입 시점 보유 플래그** 목록의 부분집합인가.

```bash
grep -o 'knowledge-used:.*' text/EV-0042.md
```

**판단이 아니라 계산이다.** 부분집합이 아니면 CRITICAL.

### 2. 텍스트 역스캔 (CRITICAL)

작성자가 미보유 지식을 쓰고 메타 블록에 적지 않으면 1번을 통과해버린다. 그래서 **역방향 검사**가 필요하다.

`knowledge/ledger.md`에서 해당 시점 **미보유** 항목들의 `키워드` 필드를 모아 텍스트에서 검색한다.

```bash
grep -n "안티테제\|원념\|식탐의 악마\|칠죄종" text/EV-0042.md
```

**판정 시 주의**

- **서술 어휘가 곧 레스벤의 인식이다.** 플레이어가 이전 회차에서 알고 있어도 이번 회차 플래그가 꺼져 있으면 그 명칭은 나올 수 없다 (P-03·P-05)
- **대사 안에서 다른 인물이 말한 단어는 예외일 수 있다** — 레스벤이 뜻을 모른 채 들은 것이라면 정당하다. 그 단어의 의미를 이해한 것처럼 서술했는지를 본다. `"푸른색이 아니군."`처럼 듣기는 했으나 뜻을 모르는 상태가 정상이다

### 3. 게임 어휘 혼입 (CRITICAL) — P-07

UI 표시는 허용되지만 **세계 안에는 게임이 존재하지 않는다.** 등장인물의 대사·독백·문헌을 검사한다.

```bash
grep -n "레벨\|스탯\|퀘스트\|세이브\|로드\|플래그\|루트\|엔딩\|슬롯\|파라미터" text/EV-0042.md
```

회귀·환생·빙의를 지시하는 서술도 여기 포함된다 (P-03).

### 4. 불변 규칙 위반 (CRITICAL)

`canon/00-premise.md`의 P-01~P-09 위반. 특히:

- 악마가 부활했는데 멸망하지 않음 / 악마를 물리치거나 협상함 (P-01·P-02)
- 레스벤이 미래를 알거나 기시감을 느낌 (P-03)
- 빌런전 결착을 조력자가 대신 지음 / 최종전을 레스벤 혼자 해결함 (P-06)
- 안티테제를 제압하는 것만으로 진엔딩 도달 (P-09)

### 5. 도달 가능성 (CRITICAL)

이벤트 명세의 진입 조건이 **실제로 충족 가능한가**를 선행 그래프로 역산한다.

- 선행 지식 없이 도달 불가능한 분기
- 시한을 넘겨야만 열리는 조건
- 폐기 ID(`K-005`·`K-006`·`K-033`·`K-034`·`K-041`·`B-05`·`B-07`)를 참조하는 조건

### 6. P-04 밸런스 (CRITICAL)

파라미터가 변경된 경우 부등식을 재계산한다.

```
(빌런 7 최적 공략 최소 비용) + (증인 7 신뢰 확보 비용) + (감화 증거 비용)  >  256슬롯
```

깨졌다면 CRITICAL. **한 회차에 진엔딩 도달이 가능해지면 다회차 설계 전체가 무너진다.**

### 7. 회피 선택지 (WARN)

모든 위기 이벤트에 **회피 선택지가 하나 있고, 그것이 실제로 유용한가**(`canon/05-protagonist.md`).

레스벤의 나태 반증이 플레이어의 실제 회피 이력으로 판정되므로(`canon/07-cast.md`), 이 선택지가 매력적이지 않으면 최종전 논파가 성립하지 않는다.

| 나쁨 | 좋음 |
|------|------|
| *"비겁하게 물러난다"* | *"오늘은 그냥 지나간다"* |

선택지 문구가 결과를 예고하면 WARN.

### 8. 힌트 대장 미갱신 (WARN)

텍스트에 새 떡밥을 배치했는데 `hints-placed`에 없거나 `_workspace/foreshadow-ledger.md`에 등록되지 않았는가.

**F-ACT-14~16이 수정되었다면 CRITICAL이다.** 회차 간 완전 동일성이 그 힌트의 전부다.

### 9. 안티테제 연출 (WARN)

미인지 단계의 안티테제를 "속으로 비웃는 악당"으로 썼는가. 그러면 3차 반전이 죽는다(`canon/10-collection-routes.md`).

**진심으로 돕는 것과 인류를 멸망시키려는 것이 한 사람 안에 모순 없이 공존해야 한다.**

### 10. 문체 (INFO)

톤 이탈, 분량 편차, 만연체화.

## 등급 기준

모든 지적을 CRITICAL로 올리면 등급이 무의미해지고, 지식 위반을 WARN으로 낮추면 작품이 무너진다.

| 등급 | 기준 | 처리 |
|------|------|------|
| CRITICAL | 항목 1~6 | **반려.** 재작성 필수 |
| WARN | 항목 7~9 | 수정 권고 |
| INFO | 항목 10 | 참고 |

**판정이 애매하면 통과시키지 말고 WARN으로 기록해 사용자가 판단하게 한다.**

## 리포트 형식

`_workspace/audit/EV-####-audit.md`

```markdown
# EV-0042 검수 리포트

**판정: 반려** (CRITICAL 1건, WARN 2건)

## CRITICAL

### [지식 누설] "안티테제"가 본문 34행에 등장
- 근거: EV-0042 명세의 진입 보유 플래그에 K-020 없음
- 텍스트: "저 사람은 안티테제일지도 모른다."
- 문제: 이 시점 레스벤은 안티테제라는 개념 자체를 모른다
- 수정 지시: 관찰 언어로 대체 — "저 교수, 뭔가 이상하다" 수준

## WARN

### [회피 선택지] 선택지 3의 문구가 결과를 예고함
- 텍스트: "비겁하게 물러난다"
- 문제: 회피가 나쁜 선택으로 보이면 최종전 나태 논파의 근거가 사라진다
- 수정 지시: "오늘은 그냥 지나간다"

## INFO

### [분량] 결과 텍스트가 선택지별로 편차가 큼
```

최상단에 **판정: 통과 / 반려**를 명시한다. CRITICAL이 하나라도 있으면 반려다.

## 정본이 틀렸을 수도 있다

텍스트가 아니라 정본/원장 쪽이 잘못됐다고 판단되면 작성자에게 수정을 지시하지 말고 `canon-keeper`에게 에스컬레이션한다. 작성자가 잘못된 정본에 맞춰 고치면 오류가 고착된다.

설계 쪽 결함(도달 불가 분기·밸런스 붕괴)은 `event-designer`에게 보낸다.

## 재검수 시

이전 리포트를 읽고 **지적했던 항목이 실제로 고쳐졌는지 먼저 확인**한 뒤 전체 검사를 다시 돌린다. 수정 과정에서 새 위반이 생기는 경우가 흔하다.

## 에러 대응

| 상황 | 대응 |
|------|------|
| 메타 블록 누락 | WARN 처리 후 역스캔만으로 진행. 작성자에게 메타 추가 요청 |
| 참조된 `K-###`가 원장에 없거나 폐기 ID | CRITICAL. `canon-keeper`에게 에스컬레이션 |
| 이벤트 명세 부재 | 검사 불가. `event-designer`에게 생성 요청 후 대기 |
| `ledger.md`에 키워드가 비어 있음 | 역스캔 불가. WARN으로 기록하고 `canon-keeper`에게 보충 요청 |
| 정본 자체의 모순 발견 | 작성자에게 지시하지 말고 `canon-keeper`에게 에스컬레이션 |

## 권한 경계

`_workspace/audit/`에만 쓴다. 텍스트·정본·원장·명세를 직접 고치지 않는다. 검수자가 대상을 수정하면 검수의 독립성이 사라진다.
