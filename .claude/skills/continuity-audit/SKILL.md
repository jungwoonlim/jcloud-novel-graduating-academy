# 정합성 검수

`continuity-auditor` 에이전트가 사용한다. 화 완성 **직후 점진 검수**한다 — 모순이 누적된 뒤에는 되돌릴 비용이 감당 불가능해진다.

## 대원칙: 읽고 판단하지 말고 대조하라

"이 화가 설정에 맞는 것 같다"는 인상 판정은 반드시 새어나간다. 지식 위반은 **판단이 아니라 계산**으로 잡는다.

---

## 검사 항목

### 1. 지식 위반 (CRITICAL)

본문 하단 `knowledge-used`의 ID 집합이 `knowledge/loop-NN.md` **보유 목록의 부분집합인가.**

```bash
# 메타 블록 추출
grep -o 'knowledge-used:.*-->' episodes/ep-0003.md
```

보유 목록에 없는 ID가 하나라도 있으면 CRITICAL. 부분집합 여부는 눈으로 훑지 말고 항목별로 대조한다.

### 2. 지식 누설 역스캔 (CRITICAL)

집필가가 미확보 지식을 쓰고 메타 블록에 적지 않으면 1번 검사를 통과해버린다. 그래서 **역방향 검사**가 필요하다.

`knowledge/ledger.md`에서 해당 회차 **미확보** 항목들의 `키워드` 필드를 모아 본문에서 검색한다.

```bash
grep -n "안티테제\|원념\|식탐의 악마\|봉인\|칠죄종" episodes/ep-0003.md
```

걸리면 메타 블록에 없더라도 CRITICAL이다.

**판정 시 주의**: 1인칭 서술에서 서술자의 어휘가 곧 주인공의 인식이다. 다만 **대사 안에서 다른 인물이 말한 단어**는 예외일 수 있다 — 주인공이 뜻을 모른 채 들은 것이라면 정당하다. 이 경우 주인공이 그 단어의 의미를 이해한 것처럼 서술했는지를 본다. refs의 `"푸른색이 아니군."`처럼, 듣기는 했으나 뜻을 모르는 상태가 회귀물의 정상적인 장면이다.

### 3. 조연 기억 위반 (CRITICAL)

`knowledge/npc-state.md` 기준, 리셋된 조연이 이전 회차 정보를 아는 것처럼 행동하는가. 회귀물에서 가장 조용히 지나가는 사고 유형이다.

주인공이 회차를 건너뛴 친밀함을 보이는데 조연이 자연스럽게 받아주는 장면을 특히 본다.

### 4. 불변 규칙 위반 (CRITICAL)

`canon/00-premise.md`의 규칙을 깼는가. 대표적으로:
- 졸업식날 악마가 부활했는데 세상이 멸망하지 않음
- 악마를 격퇴함 (악마는 격퇴 불가)
- 회귀 카운트를 초과해 회귀함
- 빌런전 결착을 조력자가 대신 지음 (2단 해결 규약 위반)
- 최종전을 주인공이 혼자 해결함 (2단 해결 규약 위반)

### 5. 정본 위반 (WARN)

캐릭터 설정·직업·이름·연표가 `canon/`과 어긋나는가. 안티테제/빌런 이름 혼동(도나덱스 vs 골드웜 등)을 특히 확인한다.

### 6. 복선 대장 미갱신 (WARN)

본문에 새 떡밥을 심었는데 `foreshadow-planted`에 없거나 `_workspace/foreshadow-ledger.md`에 등록되지 않았는가.

### 7. 회귀 카운트 정합 (WARN)

본문에 표기된 잔여 카운트가 `loops/loop-NN.md`와 일치하는가.

### 8. 문체 이탈 (INFO)

인칭·시제 혼용, 분량 편차(5,000~5,500자 범위), 만연체화.

## 등급 기준

모든 지적을 CRITICAL로 올리면 등급이 무의미해지고, 지식 위반을 WARN으로 낮추면 작품이 무너진다.

| 등급 | 기준 | 처리 |
|------|------|------|
| CRITICAL | 항목 1~4 | **반려.** 재집필 필수 |
| WARN | 항목 5~7 | 수정 권고 |
| INFO | 항목 8 | 참고 |

**판정이 애매하면 통과시키지 말고 WARN으로 기록해 사용자가 판단하게 한다.**

## 리포트 형식

`_workspace/audit/ep-NNNN-audit.md`

```markdown
# ep-0003 검수 리포트

**판정: 반려** (CRITICAL 1건, WARN 2건)

## CRITICAL

### [지식 누설] "안티테제"가 본문 34행에 등장
- 근거: knowledge/loop-02.md 미확보 목록에 K-020 포함
- 본문: "저 사람은 안티테제일지도 모른다."
- 문제: Loop 02 주인공은 안티테제라는 개념 자체를 모른다
- 수정 지시: 관찰 언어로 대체 — "저 교수, 뭔가 이상하다" 수준

## WARN

### [복선 미등록] F-HUM-02로 보이는 떡밥이 대장에 없음
- 본문 51행: "당신 수준치고는 훌륭하네요"
- 수정 지시: 메타 블록에 foreshadow-planted 추가, canon-keeper에게 대장 등록 요청

## INFO

### [분량] 5,820자 — 상한 초과
```

최상단에 **판정: 통과 / 반려**를 명시한다. CRITICAL이 하나라도 있으면 반려다.

---

## 정본이 틀렸을 수도 있다

본문이 아니라 정본/원장 쪽이 잘못됐다고 판단되면 집필가에게 수정을 지시하지 말고 `canon-keeper`에게 에스컬레이션한다. 집필가가 잘못된 정본에 맞춰 고치면 오류가 고착된다.

## 재검수 시

이전 리포트를 읽고 **지적했던 항목이 실제로 고쳐졌는지 먼저 확인**한 뒤 전체 검사를 다시 돌린다. 수정 과정에서 새 위반이 생기는 경우가 흔하다.

## 에러 대응

| 상황 | 대응 |
|------|------|
| 메타 블록 누락 | WARN 처리 후 역스캔만으로 진행. 집필가에게 메타 추가 요청 |
| 참조된 `K-###`가 원장에 없음 | CRITICAL. `canon-keeper`에게 에스컬레이션 |
| `knowledge/loop-NN.md` 부재 | 검사 불가. `canon-keeper`에게 생성 요청 후 대기 |
| `ledger.md`에 키워드가 비어 있음 | 역스캔 불가. WARN으로 기록하고 `canon-keeper`에게 키워드 보충 요청 |
| 정본 자체의 모순 발견 | 집필가에게 지시하지 말고 `canon-keeper`에게 에스컬레이션 |

## 권한 경계

`_workspace/audit/`에만 쓴다. 본문·정본·원장을 직접 고치지 않는다. 검수자가 대상을 수정하면 검수의 독립성이 사라진다.
