# 정본 및 지식 원장 운영

`canon-keeper` 에이전트가 사용한다. 이 스킬은 **무엇을 쓰는가**(정본 스키마)와 **누가 무엇을 아는가**(지식 원장)를 다룬다.

## 대원칙: canon과 knowledge의 분리

| 저장소 | 의미 | 성질 |
|--------|------|------|
| `canon/` | 세계의 진실 | 불변. 주인공이 알든 모르든 참 |
| `knowledge/` | 주인공·조연이 도달한 범위 | 회차별 가변 |

정본에 "휴멜리온은 교만의 안티테제"라고 적혀 있어도, 3회차 주인공이 그걸 안다는 뜻이 아니다. 이 분리를 지키지 않으면 집필 에이전트가 정본을 읽는 순간 주인공이 전지해진다.

### 확정된 축 (변경 시 사용자 승인 필수)

1. **정본 기준**: `설정 퇴고` 계열. 안티테제 7인이 빌런들의 원념 물건을 모아 악마를 소환한다. 악마는 의지 없는 현상이며 격퇴 불가
2. **회귀**: 유한 카운트 12회. 소진 시 진짜 멸망
3. **2단 해결 규약**: 빌런전 = 주인공 단독 결착(조력 허용) / 최종 안티테제전 = 조연 총동원
4. **불변 전제**: 졸업식날 악마가 부활하면 무조건 세상이 멸망한다

### 최초 정본화 절차

1. `refs/` 전체를 읽는다
2. 아래 **충돌 목록**을 판정한다 — 자동 결정하지 말고 근거와 함께 사용자에게 보고
3. 승인된 판정으로 `canon/` 10개 파일 생성
4. 이어서 Part 2의 지식 원장을 도출
5. **초기 상태 부트스트랩** — 회차 설계가 읽을 입력을 만든다:
   - `knowledge/loop-01.md`: Loop 01 진입 상태. 주인공은 전생 기억만 있고 악마 관련 지식은 **전무**하다. 보유 지식 비움 / 미확보에 전 항목 / 잔여 카운트 12/12
   - `knowledge/npc-state.md`: `07-cast.md` 인물로 행을 만들고 Loop 01 열은 전부 비움
   - `knowledge/acquisition-log.md`: 빈 표 헤더
   - `_workspace/foreshadow-ledger.md`: `03-antitheses.md`의 떡밥 전수를 `F-XXX-##`로 등록 (상태: 미착수)

### 정본 갱신 규약

- **추가만 한다.** 폐기는 삭제가 아니라 `09-open-questions.md`로 이동 + 사유 기록
- 이미 집필된 화에 영향을 주는 수정은 **영향 범위를 먼저 보고**하고 승인받는다
- refs에 근거 없는 설정을 요청받으면 창작하지 말고 반려한다. 사용자 확인 후에만 신규로 추가

### 캐릭터 시트 포맷

```markdown
## {이름}

- **분류**: 안티테제 / 빌런 / 조연
- **대죄**: 교만
- **표면**: 겸손하고 침착한 최연소 교수  ← 주인공이 관찰 가능한 것
- **진실**: 교만의 안티테제. 원죄 수집이 목적  ← 정본에만 존재, 발췌 금지
- **과거사**: ...
- **떡밥**: F-HUM-01 ~ F-HUM-05 (대장 참조)
- **최종전 역할**: (해당 시)
```

**표면**과 **진실**을 분리해 적는다. `loop-architect`가 집필가에게 발췌본을 만들 때, 주인공이 아직 도달하지 못한 항목은 **진실** 블록이므로 기계적으로 제외할 수 있다.

## Part 2. 지식 원장 (`knowledge/`)

### 2-1. `ledger.md` — 지식 마스터 원장

정본의 각 사실에 대응하는 **탐지 가능 단위**를 항목화한다.

```markdown
### K-003
- 내용: 졸업식날 검은 벌레떼가 아카데미 전원을 포식한다
- 대응 정본: canon/02-demons.md#식탐의-악마
- 획득 경로: 체험 (Loop 01 사망)
- 승계: 유지
- 선행 지식: 없음
- 위험도: 낮음 (아무도 믿지 않음)
- 키워드: 벌레떼, 검은 벌레
- 상태: 활성

### K-011
- 내용: 그 벌레떼는 "식탐의 악마"라는 이름을 가진 개념적 존재다
- 대응 정본: canon/02-demons.md#식탐의-악마
- 획득 경로: 문헌 또는 전언
- 승계: 유지
- 선행 지식: K-003, K-008
- 위험도: 높음 — 악마 지식 보유 자체가 이단 심문 대상
- 키워드: 식탐의 악마, 대죄, 칠죄종
- 상태: 활성
```

**필드 설명**

| 필드 | 왜 필요한가 |
|------|------------|
| `획득 경로` | 체험/목격/전언/문헌/추론 — 경로마다 주인공의 확신도가 다르다. 추론으로 얻은 지식은 흔들릴 수 있다 |
| `승계` | 회귀 시 유지되는가. 지식=유지, 물건·능력·관계=리셋 |
| `선행 지식` | **의존 그래프의 간선.** 주인공이 이 질문을 떠올릴 수 있으려면 무엇을 먼저 알아야 하는가 |
| `위험도` | 발설 시 벌어지는 일. refs의 이단심문관 즉결처형 사례가 근거 |
| `키워드` | 검수자가 본문 역스캔에 쓰는 검색어. **반드시 채운다** |

**`선행 지식`이 곧 플롯이다.** K-011을 얻으려면 K-003과 K-008이 필요하므로, 지식 습득 순서가 회차 구조를 결정한다.

### 2-2. `loop-NN.md` — 회차 시작 스냅샷

```markdown
# Loop 02 시작 시점 (잔여 카운트 10/12)

## 보유 지식
K-001, K-003, K-005

## 오신념 (B-##) — 주인공만 믿는 것
| ID | 잘못된 믿음 | 반증 시점 |
|----|------------|----------|
| B-01 | 아카데미를 피하면 살 수 있다 | Loop 02 말 (교만의 눈) |

## 미확보 — 이 회차에서 단어 하나도 쓸 수 없는 것
K-002, K-004, K-006 ~ K-047

## 이번 회차 획득 목표
K-008 (악마가 하나가 아니다)

## 회차 종료 상태
- 사망 원인: 교만의 악마와 눈이 마주침 (국경 최전방)
- 획득: K-008
- 반증된 오신념: B-01
```

**오신념을 별도 추적하는 이유:** 주인공이 계속 옳은 판단만 하면 회귀할 이유가 없다. 확신이 뒤집히는 것이 회귀물의 동력이다.

### 2-3. `npc-state.md` — 조연 지식 상태

회귀하면 주인공만 기억을 유지하고 **조연은 전부 리셋된다.** 추적하지 않으면 "저 사람이 왜 벌써 나를 의심하지?" 사고가 난다.

| 인물 | Loop 01 | Loop 02 | Loop 03 |
|------|---------|---------|---------|
| 안나(메이드) | — | 도련님이 마차에서 구토 | (리셋) 도련님이 마차에서 구토 |
| 이단심문관 | 접점 없음 | 주인공을 악마 추종자로 처형 | (리셋) 접점 없음 |

각 셀은 **그 회차에 그 인물이 주인공에 대해 알게 된 것**이다. `(리셋)` 표기로 회귀 경계를 명시한다.

최종 회차의 조연 총동원 카타르시스는 이 표가 근거다 — 회차를 거듭하며 각 조연을 더 빠르고 정확하게 돕는 법을 알아낸 결과가 최종 회차에 총집결한다.

## ID 체계 (절대 규칙)

| 접두 | 대상 |
|------|------|
| `K-###` | 지식 |
| `B-##` | 오신념 |
| `F-XXX-##` | 복선 (대상 약칭 포함) |

**ID는 재사용도 재번호도 하지 않는다.** 이미 집필된 화의 메타 블록이 그 ID를 참조하므로, 번호를 바꾸면 그 시점부터 검수가 거짓 통과를 내기 시작한다. 폐기 항목은 `상태: 폐기`로 표시만 하고 번호는 비워둔다.

## 무결성 검사

정본/원장 갱신 후 매번 확인한다:

1. 모든 `선행 지식` 참조가 실재하는 ID인가
2. 의존 그래프에 순환 참조가 없는가
3. 모든 `K-###`에 `키워드`가 채워져 있는가 (없으면 검수 역스캔이 무력해진다)
4. `loop-NN.md`의 보유 + 미확보 합집합이 `ledger.md` 활성 항목 전체와 일치하는가
