# 본문 집필

`episode-writer` 에이전트가 사용한다.

## 집필 전 필수 로드 (하나라도 빠지면 집필 시작 금지)

1. `loops/loop-NN.md` — 회차 설계서 + 정본 발췌본
2. `knowledge/loop-NN.md` — 주인공 지식 스냅샷
3. `knowledge/npc-state.md` — 해당 회차 조연 인지 상태
4. 직전 화 `episodes/ep-(N-1).md` — 문체·흐름 연속성

**`canon/`을 직접 읽지 않는다.** 필요한 정본 조각은 설계서가 발췌해 전달한다. 정본을 통째로 읽으면 미확보 지식이 컨텍스트에 들어와 반드시 새어나간다. 발췌본에 없는 정보가 필요하면 `loop-architect`에게 요청한다.

## 최우선 규칙: 서술자의 어휘 = 주인공의 인식

이 작품은 1인칭이다. 따라서 **본문에 쓰인 단어는 주인공이 그 개념을 획득했다는 선언**이 된다.

`knowledge/loop-NN.md`의 미확보 목록에 있는 것은 **단어 하나도 쓰지 않는다.** "안티테제", "원념", "식탐의 악마", "봉인" 같은 명칭은 주인공이 그 개념에 도달한 뒤에야 등장할 수 있다.

그 전에는 관찰 언어만 허용된다:

| 미확보 상태 | 허용 | 금지 |
|------------|------|------|
| K-011 (식탐의 악마라는 이름) | 검은 벌레떼, 그것들, 갉아먹는 것 | 식탐의 악마, 대죄, 칠죄종 |
| K-020 (안티테제의 존재) | 저 교수, 뭔가 이상한 사람 | 안티테제, 소환 매개 |

이 경계가 무너지면 작품이 무너진다. 독자는 "주인공이 갑자기 왜 알지?"를 정확히 감지한다.

### 조연도 기억을 잃는다

회귀하면 주인공만 기억을 유지한다. `npc-state.md`를 확인하고, 리셋된 조연이 이전 회차 정보를 아는 것처럼 쓰지 않는다. 주인공이 "안나, 저번에 말했잖아"라고 하면 **안나는 어리둥절해야 한다.** 이 어긋남 자체가 회귀물의 좋은 장면이 된다.

## 분량과 구조

- 화당 **5,000~5,500자**
- **도입 훅** → 전개 → **화 끝 절단면**

절단면은 다음 화를 읽게 만드는 지점이다. 사건이 해결된 자리가 아니라 **뒤집히기 직전**에 끊는다. `refs/스토리/1.md`의 `[눈이 마주친다.]`가 좋은 예다.

## 설명하지 말고 겪게 하라

설정을 서술로 풀어놓는 것은 웹소설에서 가장 빠른 이탈 사유다. 주인공이 몸으로 겪는 장면으로 전달한다. 악마가 무섭다고 쓰지 말고, 이가 빠지고 피부가 썩는 감각을 쓴다.

## 출력 형식

`episodes/ep-NNNN.md`에 본문을 쓰고, **하단에 메타 블록을 반드시 붙인다.**

```markdown
<!-- loop: 02 -->
<!-- knowledge-used: K-001, K-003, B-01 -->
<!-- knowledge-gained: none -->
<!-- foreshadow-planted: F-HUM-01 -->
<!-- foreshadow-paid: none -->
```

| 필드 | 내용 |
|------|------|
| `loop` | 이 화가 속한 회차 |
| `knowledge-used` | 본문에서 주인공이 **활용한** 지식 ID 전부 |
| `knowledge-gained` | 이 화에서 **새로 획득한** 지식 ID |
| `foreshadow-planted` | 이 화에서 심은 복선 |
| `foreshadow-paid` | 이 화에서 회수한 복선 |

메타 블록은 검수의 대조 근거다. 빠뜨리면 검수가 본문 역스캔으로 잡아내고 반려한다. 없는 항목은 `none`으로 채운다.

## 재집필 시

- **검수 반려** → `_workspace/audit/ep-NNNN-audit.md`를 읽고 **지적된 부분만** 수정. 전면 재작성 금지 (통과했던 부분에서 새 위반이 생긴다)
- **사용자 피드백** → 해당 부분만 수정, 나머지 문체·흐름 유지
- 수정 후 메타 블록도 갱신했는지 확인

## 에러 대응

| 상황 | 대응 |
|------|------|
| 설계서에 없는 전개가 필요 | 임의 창작 금지. `loop-architect`에게 승인 요청 |
| 발췌본에 없는 설정이 필요 | `loop-architect`에게 발췌 추가 요청 |
| 미확보 지식 없이는 장면이 성립 안 함 | 장면 설계 자체의 결함. `loop-architect`에게 보고 |
| 분량이 5,500자를 크게 초과 | 분할하되 절단면 위치를 `loop-architect`와 합의 |
