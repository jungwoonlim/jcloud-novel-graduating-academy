# 05. 주인공

## 기본 정보

| 항목 | 내용 |
|------|------|
| 이름 | **레스벤 아르덴** (Resven Arden) |
| 신분 | 아르덴 백작가 삼남 |
| 정체 | **순수 환생자** — 전생(다른 세계)의 기억을 가진 채 이 세계에 태어남 |
| 나이 | 미확정 → `09-open-questions.md` Q-12b |

### 이름에 대하여

Resurgere(다시 일어서다) + Venire(오다) — *"다시 일어나 오는 자"*.

**작중에서 이 의미를 설명하지 않는다.** 인물이 자기 이름값을 논하거나 누군가 뜻을 풀어주는 장면을 넣지 않으며, 독자가 알아차리면 그것으로 족하다. (사용자 결정, 2026-08-27)

삼남이므로 가문을 이을 일이 없고, 그래서 기대도 부담도 적게 자랐다. 이 여유가 초반의 능청스러움을 만든다.

## 환생자로서의 성질

- 갓난아이 때부터 전생의 기억을 유지했다. *"응애?"* — 아이로 살아가는 것은 상당히 힘들고 어려운 일이었다
- **판타지 세상에 귀족으로 환생한 행운**을 1등상이라 여기며 감격했다
- 사교 검술, 사교 마법, 간단한 이론과 지식을 배우며 귀족으로서의 소양을 쌓았다
- 두 번째 삶은 행복했다

**이 세계는 게임이 아니라 진짜 세계다.** 주인공에게 사전지식은 없다. 악마·안티테제·소환에 대해 아무것도 모르는 상태에서 시작한다. (→ `00-premise.md` P-07)

전생 기억은 **사고방식**으로만 작용한다: 현대적 정리·분석 습관, 상황을 항목화해 파악하는 버릇. `refs/스토리/2.md`의 *"군역을 살면서 느꼈던 정리 방법을 적용해 내가 당한던게 뭔지 정리해본다"*가 그 예다.

## 성격

- 야심이 크지 않다. 평온하고 즐거운 삶을 원한다
- 능청스럽고 가볍다 — *"드디어 왔구나! 내 꿈과 희망의 아카데미!"*
- 적당한 거리를 유지하며 사람들과 두루 잘 지낸다. 귀족 친구도 평민 친구도 있다
- **겁이 많다.** 1회차 참극 이후 공포에 완전히 지배당해 아카데미 자체를 거부한다
- 그러나 도망칠 수 없다는 것을 알게 되면 정면으로 파고든다

이 낙차 — 평범하고 겁 많은 인물이 12번의 죽음을 거쳐 세상을 구하는 자가 되는 것 — 가 성장 서사의 축이다.

## 회귀 능력

| 항목 | 내용 |
|------|------|
| 발동 | 죽으면 자동 |
| 귀환 지점 | **아카데미 입학 직전, 마차 안** (고정) |
| 횟수 | **12회 유한** |
| 승계 | 기억·지식만 |
| 소실 | 물건·재산·지위·육체 단련·기술·**모든 인간관계** |
| 원인 | **불명** — 주인공도 독자도 오랫동안 모른다 |

주인공은 처음에 횟수 제한을 **모른다.** 무한히 반복할 수 있다고 믿는 상태에서 시작하며, 유한하다는 자각이 중대 전환점이 된다.

회귀 직후에는 죽은 순간의 감각이 육체에 남아 있다. 1회차 직후에는 헛구역질과 함께 벌레가 온몸을 갉아먹던 감각이, 2회차 직후에는 몸이 썩어 문드러지던 감각이 남는다. **죽음은 누적되는 트라우마**이지 리셋이 아니다.

## 낙인

회귀할 때마다 심장 바로 위에 **검은 호가 하나씩** 그어진다. 12개가 이어지면 원이 닫힌다. (→ `06-loop-rules.md#낙인`)

주인공의 몸에서 유일하게 회귀를 증언하는 물증이며, 동시에 **남은 시간을 세는 시계**다. 옷으로 가려지는 부위라 남에게 들킬 위험은 낮으나, 의무실·목욕·부상 치료 상황에서 노출될 수 있다. 이 노출 자체가 긴장 장치가 된다.

## 특수 능력 — 없음

주인공에게는 전투력도 특수 능력도 없다. 사교 검술과 사교 마법 수준의 소양이 전부이며, 회귀해도 육체는 입학 직전으로 돌아간다.

**회차를 거듭하며 강해지는 것은 능력이 아니라 알고 있는 것이다.** 지식과 인간관계에 대한 이해만으로 문제를 해결한다.

`refs/고민.md`의 "죽을 때마다 능력 획득, 3개 슬롯" 시스템은 게임적 UI에 해당해 미도입한다. (→ `09-open-questions.md` Q-02)

## 목표의 변천

| 단계 | 목표 |
|------|------|
| 회귀 전 | 즐거운 아카데미 생활 → 졸업 후 영지 발전 / 상단 취직 |
| 1회차 직후 | 살아남는 것. 아카데미를 피하는 것 |
| 중반 | 악마가 무엇인지 알아내는 것 |
| 후반 | 소환 자체를 막는 것 |
| 최종 | **무사히 졸업하고 정문을 나서는 것** |

## 최종 도달점

*"마음을 먹고 바른 선택을 한다면 무엇이든 해낼 수 있다."*

마지막 회차에서 아카데미 생활을 온전히 마무리하고, 앞으로 뭐든지 해낼 수 있으리라는 자신감을 가지고 **아카데미 정문을 나서며** 엔딩.
