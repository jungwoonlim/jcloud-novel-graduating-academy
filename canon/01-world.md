# 01. 세계관

## 세계의 성격

평범한 중세풍 판타지 제국. **마왕도 마족도 없다.** 검술과 마법이 존재하지만 세계를 위협하는 절대악은 없으며, 사람들은 악마를 옛이야기 속 존재로 여긴다.

귀족 파벌 다툼이 유일한 정치적 소란거리이고, 그 외에는 평화롭다. 이 평온함이 졸업식날 참극의 낙차를 만든다.

## 판도라 아카데미

제국의 최고 교육기관. **귀족과 평민이 함께 배우는 것**이 이 아카데미의 정체성이며, 왕국을 제국으로 키운 힘으로 교육된다.

| 항목 | 내용 |
|------|------|
| 학제 | **4년** |
| 입학 | 3월 초 |
| 구성 | 귀족·평민 혼재 |
| 진로 | 졸업 후 각국 요직 진출, 가문 승계, 상단 취직 등 |

메이드 안나의 회고: *"판도라 아카데미는 귀족도 평민도 모두 즐겁고 행복한 시간을 보내다가 졸업하는 곳이거든요."*

이 평판은 **표면적으로는 사실**이다. 아래의 구조적 문제들은 평온한 일상 아래 잠복해 있다.

## 구조적 문제 (빌런 발생의 토양)

각 빌런은 이 구조에서 자연스럽게 발생한다. 외부에서 침입한 악이 아니다.

| 문제 | 설명 |
|------|------|
| **귀족 중심 시스템** | 실력보다 출신을 중시하는 부패한 구조 |
| **경쟁 심화** | 졸업 후 요직 진출을 위한 과도한 경쟁 |
| **권력 남용** | 기득권층의 특권 의식과 후진생 억압 |
| **이권 개입** | 외부 세력의 아카데미 내 영향력 확대 (납품·급식·상권) |

## 종교와 이단심문

성당과 신전 기사단, 이단심문관이 존재한다.

**악마에 대한 지식을 보유하거나 유포하는 것 자체가 이단 심문 대상**이다. 이단심문관은 즉결처형 권한을 가진다. 주인공이 악마에 대해 공개적으로 묻고 다니면 목숨이 위험하다.

일반 성직자(사제·수도사)는 악마에 대해 아무것도 모른다. **이단심문관만이 특별한 교육을 받는다.**

## 도서관의 악마 서적

도서관에 악마를 다룬 책이 있기는 하나 **단순한 판타지 소설**이다. 사서는 "악마 같은 건 없다"고 답한다. 정통 경로로는 진실에 닿을 수 없다는 뜻이며, 주인공을 위험한 경로(이단심문관·악마 연구자)로 밀어내는 장치다.
