## 승계 규칙

### 승계되는 것
- 주인공의 **기억과 지식** 전부
- 죽음의 **감각적 트라우마** (누적된다)

### 소실되는 것
- 물건·재산·지위
- 단련한 육체 (근력·체력이 입학 직전 수준으로 복귀)
- 습득한 기술 (재습득 필요. 단, 방법을 알므로 재습득은 빠르다)
- **모든 인간관계** — 조연들은 주인공을 처음 만나는 상태로 돌아간다

### 세계의 상태
회귀 시 세계는 입학 직전 시점으로 완전히 되돌아간다. 주인공이 이전 회차에 일으킨 변화는 전부 무효화된다. 죽은 사람도 살아 있다.

## 조연 리셋의 함의

**이것이 이 작품의 가장 중요한 구조적 제약이다.**

주인공은 12번의 회차에 걸쳐 조연들과 관계를 쌓지만, 매번 리셋된다. 그럼에도 최종 회차에서는 조연 전원의 도움을 받아야 한다 (P-06).

이 모순은 **주인공의 지식으로 해소된다.** 회차를 거듭하며 주인공은 각 인물에 대해 알게 된다:
- 무엇을 두려워하는지
- 어떤 말에 반응하는지
- 언제 도움이 필요한지
- 무엇을 숨기고 있는지

최종 회차에서 주인공은 이 축적된 이해로 **전원을 최단 경로로 아군화한다.** 리셋된 것은 관계이지 이해가 아니다.

관계 자산의 축적 상태는 `knowledge/npc-state.md`가 추적한다.

## 회귀 자각의 위험

주인공이 회귀자임을 드러내면 위험하다.

| 위험 | 내용 |
|------|------|
| **이단 심문** | 악마 지식 보유·유포는 즉결처형 사유다. 회귀 이야기는 그보다 더한 광인의 헛소리로 취급된다 |
| **펠비디아** | 상담사이므로 주인공의 이상 행동을 가장 먼저 감지할 수 있다 |
| **세라바엘** | "예측 불가능한 인간"을 연구 대상으로 보므로, 회귀라는 예외적 변수를 알아채면 가장 집요하게 파고든다 |

**주인공이 회귀 사실을 누구에게 밝히는가**는 각 회차 설계의 핵심 선택지다.

## 회귀 직후 묘사 규약

회귀 순간은 매번 다르게 쓰되 공통 요소를 유지한다:

1. **직전 사망의 감각이 육체에 남아 있다** — 벌레에 갉아먹힌 뒤라면 관절이 간지럽고, 퇴화당한 뒤라면 몸이 썩는 느낌
2. **생리적 반응** — 헛구역질, 식은땀, 떨림
3. **육체 확인** — 손가락, 발, 이가 붙어 있는지 더듬어 확인
4. **주변 인물의 걱정** — 메이드 안나 등이 놀라 반응

`refs/prologue/0.md`와 `refs/스토리/1.md`의 회귀 장면이 기준선이다.

## 낙인 — 카운트의 유일한 표시

회귀할 때마다 **심장 바로 위 피부에 검은 호(弧)가 하나씩 그어진다.**

| 항목 | 규칙 |
|------|------|
| 위치 | 심장 바로 위, 옷으로 가려지는 부위 |
| 형태 | 원의 일부인 검은 호. 잉크로 그은 듯한 가는 선 |
| 감각 | 통증 없음. 만지면 미세하게 차갑다 |
| 누적 | 회차마다 하나씩 추가되어 원에 가까워진다 |
| 완성 | **12번째에 원이 닫힌다** |
| 결과 | 원이 닫히면 무슨 일이 벌어지는지 아무도 모른다 |

낙인은 회귀 직후 이미 새겨져 있다. 그어지는 순간을 주인공이 목격하지는 못한다.

### 자각의 3단계

주인공이 이것의 의미에 도달하는 과정 자체가 서사다. 단계를 건너뛰지 않는다.

| 단계 | 지식 | 상태 |
|------|------|------|
| 1 | 몸에 못 보던 검은 선이 있다 | 무엇인지 모름. 병인가 저주인가 |
| 2 | 회귀할 때마다 선이 하나씩 는다 (`K-041`) | 상관관계 발견 |
| 3 | 이 선들이 원을 이루며, 닫히면 끝이다 (`K-033`, `K-034`) | **중대 전환점** |

### 자각 전후의 태도 변화

| 인지 전 (B-05) | 인지 후 |
|---------------|---------|
| 시행착오를 감수한다 | 한 번의 실패가 치명적이다 |
| 죽음으로 정보를 산다 | 죽지 않고 알아내야 한다 |
| 실험적으로 행동한다 | 신중하게 계산한다 |

**이 전환점 이후 작품의 장르가 바뀐다.** 시행착오 추리물에서 한 수도 틀릴 수 없는 서스펜스로 넘어간다. 12회차 배분에서 이 지점을 어디에 둘지가 `_workspace/loop-budget.md`의 최대 결정 사항이다.

### 능력 획득 시스템 — 미도입

`refs/고민.md`의 "죽을 때마다 능력 획득, 3개 슬롯" 시스템은 **도입하지 않는다.** 슬롯·교체 개념이 게임적 UI에 해당해 P-07과 충돌하기 때문이다.

주인공은 특수 능력 없이 **지식과 인간관계만으로** 문제를 해결한다. 회차를 거듭하며 강해지는 것은 능력치가 아니라 **알고 있는 것**이다.

## 사망 연출 배분 원칙

12회 사망 원인이 반복되면 긴장이 죽는다. 두 축으로 분산한다.

- **악마 7종**: 교만(퇴화) / 식탐(포식) / 분노(파괴) / 나태(정지) / 탐욕(흡입) / 색욕(번식) / 시기(동기화)
- **인간적 실패**: 이단심문관 즉결처형, 누명, 조력자 배신, 정보 발설의 대가, 시간 부족

같은 악마를 두 번 쓸 수밖에 없다면 **각도를 바꾼다** — 멀리서 목격 vs 직접 접촉, 혼자 vs 군중 속.

배분 계획은 `_workspace/loop-budget.md`가 관리한다.
