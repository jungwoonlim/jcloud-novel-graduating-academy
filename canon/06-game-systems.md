## 0. 장르 정의 — 「활협전」 계열 텍스트 육성 시뮬레이션

**본작은 「활협전(侠之道)」의 구조를 차용한 텍스트 기반 육성 시뮬레이션이다.** 웹소설이 아니며, 어드벤처 게임도 아니다. 이 정의가 모든 설계 판단의 기준이다.

### 차용하는 구조

| 활협전의 구조 | 본작의 대응 | 정의 위치 |
|--------------|-----------|----------|
| 시기 단위 행동 배분 — 한정된 일정에 수련·교류·사건을 나눠 넣는다 | 128주 × 슬롯 2 | §1 |
| 다축 스탯 육성. 한 회차에 전부 올릴 수 없다 | 무·지·교·격 4축 | §2 |
| 인물 호감도와 전용 이벤트. 깊이 들어가야 진짜 얼굴이 보인다 | 3층 구조 조연 · 심층 호감도 | §7, `07-cast.md` |
| **심마(心魔)** — 선택이 내면을 형성하고 결말을 가른다 | **성향(도구적/관계적)** | `05-protagonist.md` |
| 고정 캘린더 대사건. 준비도에 따라 결과가 갈린다 | 빌런 7 사건 | §5, `08-canonical-timeline.md` |
| 다회차 전제 — 한 회차로는 모든 것에 도달할 수 없다 | 수기 도감 · 사전 개입 경로 | §4, §5-2 |
| 다분기 결말 | 6종 엔딩 | §9 |

### 차용하지 않는 것

| 활협전 | 본작 | 사유 |
|--------|------|------|
| 무공 유파·초식 조합, 카드 전투 | 스탯 판정 중심 TBD | 레스벤은 전투 캐릭터가 아니다 (`05-protagonist.md`) |
| 강호 유랑·자유 이동 | **아카데미 폐쇄 공간** | 4년 학사일정이 곧 게임 구조 |
| 문파 선택에 따른 초반 분기 | 없음 — 시작점은 하나 | 반복 플레이의 차이는 **플레이어의 지식**에서만 나온다 |

### 본작 고유의 축

활협전에 없는 세 가지가 본작의 정체성이다.

1. **역설 게이지** (§6) — 잘할수록 마감이 앞당겨진다. 육성물의 "성실한 플레이"를 함정으로 만든다
2. **의심도** (§3) — 최적 공략 자체가 위험을 부른다. 효율과 안전이 반비례한다
3. **감화** (§8) — 최종 관문이 전투력이 아니라 *128주 동안 어떤 사람이었는가*로 판정된다

> 셋 다 **효율적 플레이를 처벌하는 장치**다. 이것이 본작이 활협전에서 갈라져 나오는 지점이며, P-08의 주제(*마음을 먹고 바른 선택을 한다면*)를 시스템으로 번역한 결과다.

## 1. 시간

| 항목 | 값 |
|------|-----|
| 총 기간 | 4년 × 2학기 × 16주 = **128주** |
| 주당 행동 슬롯 | **2** |
| 총 행동 횟수 | 256회 |
| 시간 되돌리기 | **없음** |

### 행동 종류

| 행동 | 슬롯 | 산출 | 비고 |
|------|:----:|------|------|
| 수업·수련 | 1 | 스탯 | 학사 일정에 따라 선택지가 바뀐다 |
| 조사 | 1 | 지식(`K-###`) | 장소·시기·선행 지식이 조건 |
| 교류 | 1 | 호감도 | 대상의 일과에 따라 접근 가능 시기가 다르다 |
| 잡무·의뢰 | 1 | 자금·평판 | 격(格) 상승의 주요 경로 |
| 사건 개입 | 2~ | 빌런 공략 진행 | 시한이 있다 |
| 휴식 | 1 | 상태 회복 | 과로 페널티 해소 |

### 설계 제약 (P-04)

**128주로 전부 할 수 없어야 한다.** 최적 순서로 빌런 일곱을 처리하는 데 드는 최소 비용과, 친구 일곱 확보 + 감화 증거 일곱을 만드는 비용의 합이 256슬롯을 **초과**하도록 유지한다.

> 밸런싱 시 이 부등식이 깨지지 않는지 매번 검증한다. 깨지는 순간 다회차 플레이의 이유가 사라진다.

## 2. 스탯

레스벤에게 특수 능력은 없다(`05-protagonist.md`). 강해지는 것은 능력치가 아니라 **열리는 선택지**다.

| 축 | 내용 | 주 용도 |
|----|------|--------|
| **무(武)** | 검술·마법·체술 | 빌런 사건의 강제 충돌, 최종전 1단계 제압 |
| **지(知)** | 조사·추리·문헌 해독 | 지식 획득 속도, 최종전 3단계 논파 |
| **교(交)** | 신뢰·화술·공감 | 호감도 상승률, 증인 확보, 감화 |
| **격(格)** | 신분·평판·인맥 | **상위 계층 접근권** |

### 격(格)이 접근 난이도를 만든다

[08-canonical-timeline.md:32-38](08-canonical-timeline.md#L32-L38)의 *"1학년 신입생이 이사회 멤버를 조사할 수는 없다"* 를 구현하는 축이다.

| 계층 | 요구 격 | 대상 빌런 |
|------|:-----:|----------|
| 학생 | 최저 | 아르토리우스 |
| 급식·시설 | 낮음 | 글러트니 |
| 교수 | 중 | 라스푸틴 |
| 상인·길드 | 중 | 골드웜 |
| 학부모회 | 높음 | 엔비 |
| 행정처 | 높음 | 슬로스 |
| 이사회 | 최고 | 바실리스크 |

**금지가 아니라 요구치다.** 1학년이라도 격을 극단적으로 몰아 올리면 바실리스크에 닿을 수 있으나, 그 대가로 다른 모든 것을 포기하게 된다.

## 3. 의심도

> 구 `06-loop-rules.md`의 "회귀 자각의 위험"이 이 시스템으로 전환되었다. 회귀는 사라졌으나 **미래를 아는 것처럼 행동하는 위험**은 남는다.

### 상승 요인

| 행동 | 상승폭 |
|------|:-----:|
| 아직 발생하지 않은 사건에 개입 | **대** |
| 접근 권한 없는 정보에 도달 | 대 |
| 악마·소환 관련 공개 조사 | 대 |
| 격에 맞지 않는 인물과 접촉 | 중 |
| 사건 해결 시 과도하게 눈에 띔 | 중 |
| 안티테제 앞에서 정체를 아는 듯 행동 | **극대** |

**최적 공략 그 자체가 의심도를 올린다.** 효율적으로 플레이할수록 위험해지는 것이 이 시스템의 요점이다.

### 임계 반응

| 구간 | 반응 |
|:----:|------|
| 0~24 | — |
| 25~49 | **펠비디아**가 상담을 제안한다. 거절해도 관찰이 시작된다 |
| 50~74 | **세라바엘**이 연구 대상으로 표시. 조사 결과 오염·정보 차단 |
| 75~99 | 이단심문관의 내사. 특정 행동 봉쇄 |
| 100 | **즉결처형 — 배드엔딩** |

### 하강 수단

| 수단 | 비용 |
|------|------|
| 근신 (조사·개입 중단) | 시간 |
| 평판 소모 | 격 하락 |
| 특정 인물의 비호 | 해당 인물 호감도 |

의심도는 **자연 감소하지 않는다.** 반드시 자원을 지불해야 한다.

## 4. 지식과 수기(手記)

### 4-1. 회차 내 지식

`knowledge/ledger.md`의 `K-001`~`K-077`이 그대로 플래그다.

- 획득 조건: 장소 + 시기 + 선행 지식 + 지(知) 요구치
- 효과: 특정 선택지·조사 경로·대사 분기의 해금
- **레스벤은 획득한 것만 안다.** 플레이어가 알아도 레스벤이 모르면 선택지는 열리지 않는다

### 4-2. 마스터키 지식

일부 지식은 하나로 여러 자물쇠를 연다.

| ID | 내용 | 효과 |
|----|------|------|
| `K-019` | 안티테제는 성격이 정반대다 | 안티테제 7인 **일괄 인지 해금** |
| `K-028` | 원념 물건이 전부 내 손을 거쳐 갔다 | 역설 게이지의 정체 공개 |
| `K-051` | 빌런들이 서로 얽혀 있다 | 축 A/축 B 구조 공개, 최적 순서 추론 가능 |
| `K-038` | 하나만 막아도 소환은 성립하지 않는다 | 유예 엔딩 경로 해금 |
| `K-042` | 절망의 원점에 닿아야 한다 | **감화 루트 해금** |

### 4-3. 수기 도감 (P-05)

회차를 넘어 승계되는 **유일한** 것.

| 기록됨 | 기록되지 않음 |
|--------|-------------|
| 지식의 제목 | 지식의 내용 전문 |
| 획득 시기 (학년·학기) | 획득에 필요했던 선행 조건 |
| 획득 장소·계기 | **그래서 무엇을 해야 하는가** |

예시 표기:

```
K-019  안티테제는 성격이 정반대다
       3학년 1학기 · 휴멜리온 강의 검증 · 세피르 동석
```

플레이어는 다음 회차에 이 좌표로 곧장 갈 수 있으나, **세피르를 그때까지 확보해두는 것**은 여전히 스스로 해내야 한다.

> **미해결**: `K-019`·`K-028`은 제목만으로 스포일러가 된다. 초회차 미획득 시 제목을 가릴지 결정 필요. → `09-open-questions.md`

## 5. 빌런 공략

### 5-1. 판정

각 사건은 **발생 주차**와 **해결 시한**을 가진다. 시한 내에 결착하지 못하면 실패로 확정되고 피해가 확산된다.

| 요소 | 내용 |
|------|------|
| 접근 | 격(格) 요구치 통과 |
| 조사 | 지(知) + 필요 `K-###` 보유 |
| 결착 | 무(武) 또는 지(知) 판정 — 사건별로 다르다 |
| 조력 | 조연이 정보·도구·시간을 제공. **결착은 대신할 수 없다** (P-06) |

### 5-2. 사전 개입 경로 — 다회차의 핵심

사건 발생 **이전에** 개입하면 요구치가 대폭 낮아진다. 그러나 그 경로는 **무엇이 언제 터지는지 아는 플레이어에게만** 보인다.

| | 사후 개입 | 사전 개입 |
|---|---|---|
| 격 요구치 | 100% | 40% TBD |
| 소요 슬롯 | 4~6 | 2~3 TBD |
| 의심도 | 소 | **대** |
| 조건 | 사건 발생 | 해당 `K-###` 수기 보유 + 정확한 주차 도달 |

[08-canonical-timeline.md:59](08-canonical-timeline.md#L59)의 *"1학년 신입생이 행정처장의 횡령 증거를 어디서 찾아야 하는지 이미 알고 있어야 한다"* 가 이 규칙이다.

### 5-3. 순서 함정

발생 순서와 최적 순서는 정반대다([08:48-57](08-canonical-timeline.md#L48-L57)).

- 가장 먼저 눈에 띄는 **아르토리우스가 최악의 첫 수**다 (`K-055`, `B-09`)
- 축 A의 뿌리인 **슬로스는 여섯 번째**로 터진다
- 순서대로 따라가는 초회차 플레이어는 반드시 최악의 경로를 밟는다

**이 함정은 완화하지 않는다.** 초회차 실패가 설계 의도다.

## 6. 역설 게이지 (P-01)

빌런을 무너뜨릴수록 원념 물건이 세상에 나와 안티테제가 회수한다. → `10-collection-routes.md`

| 표시 | 규약 |
|------|------|
| 형태 | 정체불명의 눈금 7단계 |
| 라벨 | **없음.** 무엇을 세는지 표시하지 않는다 |
| 정체 공개 | `K-028` 획득 시 |
| 효과 | 눈금 1단계마다 최종 결전이 앞당겨진다 |

| 눈금 | 결전 시점 |
|:---:|---|
| 0 | 졸업식 당일 |
| 1~6 | 비례 단축 |
| **7** | **4학년 2학기 초** |

> 초회차 플레이어는 성실하게 일곱을 전부 해결하고, 뿌듯한 상태로, 가장 준비되지 않은 시점에 급습당한다. **이것이 이 게임의 첫 번째 진짜 교훈이다.**

### 방치 경로도 실패한다

| 선택 | 결과 |
|------|------|
| 전부 해결 | 결전이 최대로 앞당겨짐 |
| 전부 방치 | 피해 확산 + 조연 이탈. 원념은 어차피 축적됨 |
| 아카데미 이탈 | 소환은 그대로 진행 |

**어느 쪽도 답이 아니라는 것**을 플레이어가 인지하는 것이 중반의 전환점이다.

## 8. 감화 (P-09)

### 8-1. 성립 조건

감화는 대사 선택으로 성립하지 않는다. **논박이 아니라 절망을 뒤집는 구체적 사례**([08:114](08-canonical-timeline.md#L114))가 필요하며, 그 사례는 플레이어가 128주에 걸쳐 **만들어 둔 상태**다.

| 필요 요소 | 내용 |
|----------|------|
| 1. 정체 인지 | `K-019` |
| 2. 방법론 | `K-042` |
| 3. 원점 파악 | 해당 인물 전용 `K-###` |
| 4. **증거** | 특정 조연이 특정 상태로 확보되어 있을 것 |
| 5. 교(交) 판정 | 최종 대치 시점 |

4번이 핵심이다. 증거는 결전 당일에 만들 수 없다.

### 8-2. 순서

| 순번 | 대상 | 근거 |
|:---:|------|------|
| 1 | **델리고르** | 자기기만이 명시된 유일한 인물(`K-040`). 이미 흔들리고 있다 |

### 8-3. 제압과의 관계

| 경로 | 결과 |
|------|------|
| 제압만 | 무력화. 승리하되 진엔딩 아님 |
| 감화만 | 강당 진입 자체가 불가능 — 결계·함정·델리고르(`K-075`) |

**제압이 먼저다.** 말할 기회를 얻으려면 먼저 이겨야 한다(`K-074`). → `08-canonical-timeline.md#공략`

## 9. 엔딩 분기

| 엔딩 | 조건 |
|------|------|
| **멸망** | 기본. 소환 성립 |
| **즉결처형** | 의심도 100 |
| **유예** | 원념 물건 1개 이상 차단, 안티테제 미처리. 졸업하나 후일담이 어둡다 |

| **진엔딩** | 7인 전원 감화 + 친구 7인 확보 + 졸업 |

진엔딩 최종 화면은 **아카데미 정문을 나서는 레스벤**이다 (P-08).
