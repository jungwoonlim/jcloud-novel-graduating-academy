# 게임 전환 설계서

「아카데미 졸업하기」를 웹소설에서 **텍스트 기반 육성 시뮬레이션**(「활협전」 계열)으로 전환한다.

**결정일:** 2026-09-02
**결정 사항:** 회귀 설정 전면 폐기(A안) · 소설 트랙 종료 후 게임 단독 진행

---

## 1. 핵심 전환 — 루프의 주체 이동

소설의 12회 회귀는 **"죽고 다시 시작하며 아는 것이 늘어난다"**를 서사로 시뮬레이션한 장치였다. 게임에서는 그 행위 자체가 플레이어의 기본 동작이므로, 장치가 불필요해진다.

| | 소설 | 게임 |
|---|------|------|
| 반복하는 주체 | 레스벤 (12회 제한) | **플레이어** (무제한) |
| 승계되는 것 | 레스벤의 기억 | **플레이어의 이해** |
| 리셋되는 것 | 관계·육체·재산 | 세이브 데이터 전부 |
| 반복의 근거 | 낙인·회귀 규칙 | 설명 불필요 |

[08-canonical-timeline.md:61](../canon/08-canonical-timeline.md#L61)의 *"회귀자만이 할 수 있는 일이며, 이 배치 자체가 회귀 설정의 존재 이유다"* 는 문장이 그대로 **"이 배치 자체가 다회차 플레이의 존재 이유다"** 로 치환된다. 연표 설계는 손댈 것이 없다.

### 함께 폐기되는 것

- 12회 제한 (P-03)
- 낙인 — 심장 위의 검은 호
- 발설 금지 — 회귀를 말하면 심장이 찢긴다
- 귀환 지점 고정 (P-04) · 승계 규칙 (P-05)
- 순수 환생자 설정 (P-07) — 레스벤은 전생 기억 없는 이 세계 사람이 된다

### 대체되는 것

**게임적 UI 금지(P-07)가 폐기되고 그 자리에 P-07′이 들어선다: 세계는 여전히 게임이 아니다.**

시스템창·수치·주차 UI는 **플레이어에게만 보이는 것**이며, 레스벤은 자신이 조작당하고 있다는 사실을 모른다. 이 구분을 놓치면 흔한 게임 빙의물이 된다. 등장인물 대사에 "레벨", "퀘스트", "플래그" 같은 어휘는 여전히 금지다.

## 2. 게임 시스템

### 2-1. 시간 — 주차 배분

4년 × 2학기 × 16주 = **128주**. 매주 행동 슬롯 2개를 배분한다.

| 행동 | 소모 | 획득 |
|------|------|------|
| 수업·수련 | 1슬롯 | 스탯 |
| 조사 | 1슬롯 | 지식(K-###) |
| 교류 | 1슬롯 | 호감도 |
| 잡무·의뢰 | 1슬롯 | 자금·평판 |
| 사건 개입 | 2슬롯+ | 빌런 공략 진행 |

시간이 유일한 진짜 자원이다. 128주로는 빌런 일곱을 전부 최적 순서로 처리하면서 친구 일곱과 증거까지 모을 수 없다. **첫 회차에 모든 것을 하려는 시도는 반드시 실패한다.**

### 2-2. 스탯 4축

레스벤은 특수 능력이 없다 — [05-protagonist.md](../canon/05-protagonist.md)의 원칙을 유지한다. 강해지는 것은 능력치가 아니라 **접근 가능한 선택지**다.

| 축 | 역할 | 관문 |
|----|------|------|
| **무(武)** | 검술·마법 | 빌런 사건의 강제 충돌, 최종전 1단계 제압 |
| **지(知)** | 조사·추리·문헌 | 지식 획득 속도, 최종전 3단계 논파 |
| **교(交)** | 신뢰·화술 | 호감도 상승률, 증인 확보 |
| **격(格)** | 신분·평판 | 상위 계층 접근권 — 1학년이 이사회에 닿지 못하는 이유 |

### 2-3. 의심도 — 양날의 게이지

구 `canon/06-loop-rules.md`의 "회귀 자각의 위험" 섹션이 통째로 시스템이 된다(커밋 `f9d6e83` 시점 원문 참조). 회귀는 사라지지만 **위험은 남는다.**

미래를 아는 것처럼 행동할수록 의심도가 오른다. 아직 터지지 않은 사건에 미리 개입하는 것 — 즉 **최적 공략 그 자체**가 의심도를 올린다.

| 임계 | 반응 |
|------|------|
| 낮음 | — |
| 중간 | **펠비디아**가 상담을 제안한다 (상담사이므로 이상 행동을 가장 먼저 감지) |
| 높음 | **세라바엘**이 연구 대상으로 표시한다. 조사 방해·정보 오염 |
| 임계 초과 | **이단심문** — 즉결처형 배드엔딩 |

효율적으로 플레이할수록 위험해지는 구조다. 소설에서 레스벤이 감당하던 고독이 게임에서는 **플레이어가 감당하는 리스크**가 된다.

### 2-4. 지식 — K-### 플래그 + 수기(手記)

`knowledge/ledger.md`의 K-001~K-077이 **그대로 게임 플래그 테이블**이다. 재작성 불필요.

| 계층 | 승계 | 내용 |
|------|:----:|------|
| **회차 내 지식** | ✕ | 레스벤이 이번 인생에 실제로 아는 것. 선택지 해금 조건 |
| **수기 도감** | ○ | 이전 회차에 획득했던 K의 **제목과 획득 위치**만 영구 기록 |

수기에는 *"K-019 — 안티테제는 성격이 정반대다 / 획득처: 3학년 1학기, 세피르와 함께 휴멜리온 강의 검증"* 까지만 남는다. **"그래서 어떻게 하라"는 없다.**

> A안의 정신을 지키면서 플레이 가능성을 확보하는 장치다. 승계되는 것은 지식이 아니라 **지식의 좌표**이며, 판단은 매번 플레이어가 다시 한다. 소설의 *"리셋된 것은 관계이지 이해가 아니다"* 가 플레이어 층위에서 그대로 보존된다.

### 2-5. 빌런 7 — 시한부 공략

[08-canonical-timeline.md:22-30](../canon/08-canonical-timeline.md#L22-L30)의 배치표가 곧 게임 캘린더다.

각 사건에는 **발생 주차**와 **해결 시한**이 있고, 공략에는 스탯·격·인맥 요구치가 걸린다. 1학년이 바실리스크를 건드리지 못하는 것은 금지되어 있어서가 아니라 요구치가 압도적이기 때문이다.

**사전 개입 경로**가 핵심이다. 사건이 터지기 전에 개입하면 요구치가 크게 낮아지지만, 그 경로는 **무엇이 언제 터지는지 아는 플레이어에게만 보인다.** [08:59](../canon/08-canonical-timeline.md#L59)의 *"아직 터지지도 않은 사건에 미리 개입해야 한다"* 가 이렇게 구현된다.

발생 순서와 최적 순서가 정반대라는 설계([08:48-57](../canon/08-canonical-timeline.md#L48-L57))는 **초회차 플레이어를 반드시 최악의 경로로 유도한다.** 눈앞의 아르토리우스를 치는 것이 가장 자연스럽고 가장 나쁜 첫 수다.

### 2-6. 역설 게이지 — 이 게임의 중심 트릭

**빌런을 무너뜨릴수록 원념 물건이 세상에 나오고, 소환이 빨라진다.**

[00-premise.md:24](../canon/00-premise.md#L24)의 역설을 게이지로 노출한다. 다만 플레이어에게 그 의미를 알려주지 않는다 — 화면에는 정체불명의 눈금만 차오른다.

| 빌런 처리 | 최종 결전 시점 |
|:---:|---|
| 0/7 | 졸업식 당일 |
| 1~6/7 | 졸업식 즈음 (비례 단축) |
| **7/7** | **4학년 2학기 초 — 석 달 앞당겨짐** |

성실한 초회차 플레이어는 일곱 사건을 전부 해결하고, 뿌듯한 상태로, **준비가 하나도 안 된 4학년 2학기 초에 급습당한다.** 이것이 이 게임의 첫 번째 진짜 교훈이며 다회차 플레이의 출발점이다.

### 2-7. 안티테제 7 — 3단계 인식

| 단계 | 플레이어에게 보이는 것 |
|------|--------------------|
| **미인지** | 순수한 조력 NPC. 교수·사서·사제·메이드·상담사로서 실제로 유용한 버프와 정보를 준다 |
| **인지** | K-019 획득 시 일괄 해금. 4년간 자신을 도와준 일곱이 전부 적이었음 |
| **공략** | 제압(무) / 논파(지) / **감화(교 + 증거)** |

초회차에서 안티테제는 **진심으로 도움이 된다.** 세라바엘은 성실하게 자료를 찾아주고, 아스카바르는 밥을 챙겨주고, 펠비디아는 상담을 해준다. 플레이어가 그들에게 실제로 신세를 진 만큼 반전이 아프다.

### 2-8. 감화 — 진루트

[08-canonical-timeline.md:96-124](../canon/08-canonical-timeline.md#L96-L124)의 개심 설계가 그대로 진루트 조건이다. 논박이 아니라 **절망을 뒤집는 구체적 사례**를 보여주는 것이므로, 감화 조건은 대사 선택지가 아니라 **특정 NPC를 특정 상태로 만들어 둔 것**이다.

| 인물 | 절망의 원점 | 감화 조건의 성격 |
|------|-----------|----------------|
| 델리고르 | 자신은 재능 없이 해냈는데 남들은 쉽게 포기한다 | 자기기만이 명시된 유일한 인물 → **첫 돌파구** |
| 아스카바르 | 건강한 것을 만들어도 자극적인 것만 찾는다 | 미각 상실 + 보름의 밥 한 끼 |
| 도나덱스 | 전부 기부하는데 더 요구하기만 한다 | 인정 갈망 |
| 휴멜리온 | 자신도 겸손한데 못난 자들이 교만을 부린다 | 자각 없는 교만을 자각시키기 |
| 칼미라 | 유혹하지 않았는데 사람들이 욕망을 품는다 | 신을 저주하며 죽는 결말의 회피 |
| 펠비디아 | 진심으로 축하해도 서로를 질투한다 | 공감 부재 |
| 세라바엘 | 아무리 연구해도 인간만은 일관성이 없다 | 7인의 설계자 — **최후** |

소설의 "증인단 7인"이 게임에서는 **수집 요소**가 된다. 목적 없이 사귄 친구가 나중에 유일한 열쇠였다는 구조는 그대로 유지되며, 게임에서는 플레이어가 그 사실을 **다음 회차에 가서야** 깨닫는다.

### 2-9. 엔딩

| 엔딩 | 조건 |
|------|------|
| **멸망** | 기본. 아무것도 모르는 초회차 |
| **즉결처형** | 의심도 임계 초과 |
| **유예** | 원념 물건만 차단. 졸업하지만 후일담이 어둡다 — *막은 것이 아니라 미룬 것* |
| **제압** | 안티테제 7인 무력화. 승리하되 대가가 있다 |
| **감화 N** | 감화 인원수에 따라 후일담이 밝아진다 |
| **진엔딩** | 7인 전원 감화 + 친구 7인 확보 + 졸업 |

[00-premise.md:88](../canon/00-premise.md#L88) P-08 *"목표는 격퇴가 아니라 졸업이다"* 가 그대로 승리 조건이 된다. 마지막 화면은 아카데미 정문을 나서는 레스벤이다.
